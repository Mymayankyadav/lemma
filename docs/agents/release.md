## Independent audit before saved schedules exist

A circular bootstrap dependency must not compel unsafe merges: if the five ordinary ChatGPT scheduled slots are not yet installed or exposed, an **owner-authorized one-off interactive ChatGPT review** may establish independent source review during `legacy` or `shadow` only. This is **not** a replacement for scheduler installation/ACKs, an extra recurring agent, or a self-CLEAR exception. The owner still must arrange a genuinely separate reviewer execution; the authoring/merging execution may not also be its reviewer. Ordinary GitHub account attribution alone does not prove independence because tool clients can share an account.

Before the independent review, the reviewer appends a fresh `RUN` to Agent Log #455 containing its actual invocation nonce, `slot=interactive`, observed start time, scope and explicit non-scheduled mode. Use GitHub's **returned comment ID** as `run:<id>` and preserve the exact `https://github.com/Mymayankyadav/lemma/issues/455#issuecomment-<id>` URL; never manufacture a scheduled slot, saved-task ID, start or runtime. The review records the full PR head and accepted requirement revision, the complete source/tests/CI/artifacts checked, source and merger lineage, relevant holds and verdict. The reviewer must not have authored, copied or merged the reviewed work, and a later BLOCK still wins. Do not mark a review CLEAR if required CI, strict first-attempt evidence or task-specific acceptance is missing.

For this **bootstrap-only** reviewer, `evaluateRelease` accepts `v.slot='interactive'`, `v.review_channel='interactive_bootstrap'`, `v.run_id`, `v.run_record_url`, `v.started_at`, `v.invocation_nonce`, `v.separate_execution_verified=true` and the usual independently verified `v.provenance_verified/provenance_ref/evidence_refs`, only when the caller also documents `e.protocol_mode='legacy'|'shadow'`, `e.bootstrap_review_authorized=true`, `e.bootstrap_authorization_verified=true` and `e.bootstrap_authorization_ref`. These booleans are not self-authenticating: **the release operator must inspect the original owner authorization and the complete immutable GitHub author/reviewer history**, including copied source, actual distinct invocation and same-account risks, before asserting them. An agent-authored handoff is not by itself an owner-authored decision. Any unknown provenance or shared authoring execution is a BLOCK. The ordinary scheduled reviewer path remains unchanged, and bootstrap reviews are invalid for active/cutover/rollback modes. Neither reviewer path waives `scripts/merge-gate.ts`, all seven exact-head CI jobs, first-attempt performance or a separate authorized merge/verification actor.
