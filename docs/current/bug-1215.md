## bug #1215 — remove tracked node_modules symlink

The merged N52 branch accidentally included the Git index entry `node_modules`
(mode `120000`) pointing to an absolute path on one developer's machine.
The repository already ignores `node_modules/`, but ignore rules do not
untrack an existing committed entry. This bug fix removes the Git symlink from
the tree without changing the package lockfile, dependencies, CI rules, or
N52 timer behavior.

The new unit regression uses `git ls-files --stage -- node_modules` to inspect
the committed checkout, not `lstat` or the installed directory: `npm ci` may
replace an accidental link before the test runs, hiding this fault in ordinary
filesystem checks. The same test fails against the pre-fix Git tree and
passes only when no root `node_modules` entry is tracked.
