## N109 — MCP study planner links and N52 timer operations

The N36.1 study_entries registry now appends the timer controls `take_lease`, `next_phase`, `exclude_minutes` and writable `calendar_block_id`, `preset_id`, `energy` fields. The calendar_blocks row appends `task_id`; all legacy entries remain in their original order. The capability manifest and owner-editable MCP paths reflect these command routes.

The compatible owner-scoped `study_command_lifecycle` create path permits two additional draft fields only. Before inserting, it verifies a selected calendar block belongs to the owner and is a study block, and verifies a selected preset belongs to the owner and is not archived. Composite FKs remain the storage boundary. The subsequent `start` operation captures the N52 preset configuration via its existing database trigger; no owner IDs are accepted from clients. Lease/phase/exclusion operations continue through the existing N52 command and its audited receipts.
