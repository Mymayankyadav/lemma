## N253 Mathematical typing and inline completion experiments

The control is the shipping faster-typing opt-in from commit `421967853f6e070bced42751d9073a27dc3fd1cf`. It includes N250’s on-demand model installation and sparse strip at empty or new sentences. Compare variants on the same input schedule, using a single browser harness and identical tracing settings.

The proposed strip qualification requires at least two percentage points more simulated keystroke savings and one point more exact boundary top-three coverage on an independently frozen cohort. Both paired 95% intervals must exclude zero in the favorable direction. For grey text, measure full literal exactness, on-time coverage, incremental action savings and the learner’s actual interaction cost. Keep physical-phone and human outcomes separate from public replay measurements.
