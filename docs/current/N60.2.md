## N60.2 persistent dated plans and transactional live path (chat-94357#z6m2)

The day-plan demo adapter persists a per-tab owner-style fixture and supports a dated, version-checked create/update/preview/commit/close/reopen lifecycle. Preview retains explicit placed, unplaced and carried-over items and verifies captured task/block versions; commit rechecks those versions before applying. Closure applies only to the selected existing day, rejects future civil dates in its owner time zone, and can be reopened without changing other dates. Plan and item pages use filter-bound keyset cursors with exact totals and 1–50 limits. N60.1's strict civil-date and availability model remains the shared source of validation. The live adapter will route writes to the existing versioned day_plans_command SQL and require server-side source checks. Production deployment and CI verification are not claimed by this note.
