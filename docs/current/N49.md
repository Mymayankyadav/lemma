## N49 Proposal draft storage (WIP · chat-62804#p9h6)

An additive, owner-scoped proposal_drafts table provides proposal and target IDs, version snapshots, complete edit JSON, positive optimistic draft versions, status lifecycle, and edit timestamps. A composite owner foreign key prevents linking to another owner's proposal; owner RLS permits SELECT only; authenticated browser DML is explicitly revoked. Changes will be journalled and undoable through the N36 registry.
