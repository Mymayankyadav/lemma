## N49 Owner-scoped proposal drafts and submit without implicit approval (in progress)

The additive proposal_drafts table stores immutable base proposal/target versions, editable complete draft payload and durable draft/saved/submitted/discarded states. The owner-only receipt-backed command has create, save, submit and discard, optimistic version checks, exact replay, rejection of superseded drafts, server-side target-version assertions and an atomic submit through N92 `revise_proposal` that creates a successor while withdrawing the original (never approving either). The single audit action is fully undoable. A service-role `mcp_command` dispatch uses the same receipts and retains the owner and provenance. Audit triggers register the new table with generic undo and MCP resource dispatch. Browser DML is explicitly revoked. PGlite acceptance asserts owner isolation, retry, stale version, submit and no implicit approval. CI v2.7 now permits required new-table DML revocations. The PR requires final SQL gate and independent production SQL review before merge.
