## N204 Adaptive information placement

The Atlas, Inbox, and checkpoint panels use separate feature components. Inbox keeps one row per suggested link and groups batch decisions under Review links by kind. Calendar draws placement suggestions in the grid. Settings → Advanced contains model health, track record, and decision details. Path shows the remaining-work estimate beside its progress.
