## N59.2 study goals live adapter

The stable getGoalApi facade now chooses the owner-RLS live adapter for Supabase sessions, while preserving the sessionStorage demo adapter and injection seam. Read requests use authenticated table RLS, exact counts, 1-50 sorted keyset pages (start/end/UUID), bounded filter-locked cursors and nullable ID scope filters. Create, update, archive, restore and delete use study_goals_command schema v1 with positive expectedVersion, server receipts and same-operationId retry after uncertain network transport errors. SQL enforces owner scope, inclusive civil date ranges, IANA zones, overlap (including restore), receipts and undo. Client validation and typed conflict/not-found mapping avoid silently accepting stale writes.

Tests cover facade, RLS-shaped filters, lifecycle command envelopes, versions, network retry, error mapping, time-zone/civil validation and cursor paging. Build feature; no UI or flags modified.
