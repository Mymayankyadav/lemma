## N207 Tutor reading and listener presence

The composer starts with the keyboard closed. The latest tutor question is pinned and the session menu contains Connection. Authorized connector reads write `listener_seen_at` and the owner history exposes it as Listening or Replying. The connector waits up to 25 seconds on an individual request and tells the host to retry for about ten minutes.
