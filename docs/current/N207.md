## N207 Tutor reading and listener presence

Tutor chat opens with the keyboard closed. The header shows the checkpoint title and a presence light, with a compact session strip below it. Tap the light to read **Listening**, **Replying** or **Not listening**. While online, a current reply lease shows **Replying**. Otherwise, an authorized listener check within the past 30 seconds shows **Listening**. The connector can wait up to 25 seconds for the next authorized turn. The host instructions repeat that request for about ten minutes or until the learner asks it to stop.

The latest tutor question is pinned above the transcript. **On the table** opens its full text and math. The session menu holds Connection, Search, the study timer, the plan and checkpoint details. The answer’s ellipsis holds hint, stuck, notation help, photos, context and typing history. **Scratch** opens the image drawing surface when it is available. **Keys** returns to the custom math keyboard.

Touch entry uses the custom keyboard, and hardware keys and IME share the editor. Three suggestions keep the strongest choice in the center. The keyboard has enlarged key previews, contiguous hit cells, long-press digits, repeating Delete and space-bar caret movement. Symbol categories fit without vertical scrolling and prose scaffolds use two pages. Local completion finishes started words and exact aliases or reformats supplied shorthand such as `let x in A`. The learner supplies the mathematical choices. Six familiar lowercase typos in prose can be corrected on a separator and reversed with Delete. [Keyboard research and tests](../ui-plan/2026-11-20/keyboard-research.md)

**Browse symbols** searches names, TeX commands and common shape descriptions in the keyboard, with typo tolerance. **Settings → Tutor → Math input beta** enables the on-device **Draw symbol** pad. One compact row holds up to three matches and three possible extensions with accessible group labels and a loading spinner. A tap inserts the chosen glyph at the saved caret. Recognition uses Detypify. The current model asset set uses explicit selection. Chromium verified real inference and offline restart with prepared assets. Physical-device accuracy, latency and haptics remain unmeasured. [Runtime validation](../../public/models/tutor-symbols/detypify-0.3.0-lemma-v1/README.md)
