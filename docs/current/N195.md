## N195 Live core study and accessibility

The November 20 implementation plan connects the exact-card flow shipped in N189, the first-use preview in N194, and the shared server-owned receipt in N191. The fixtures below exercise the production contracts on isolated accounts.

| Starting state | Action | Required durable result |
|---|---|---|
| Empty Review or Cards | Create a path and card twice with the same intent, including after reload | One project, one note, one card and the original identifiers |
| Mixed queue | Open the saved card, reveal it, choose a rating and retry after losing the acknowledgement | One review, one schedule transition and one advance of the same run item |
| One path with two checkpoints and another path due | Start from a checkpoint, concept or path | Every frozen item belongs to the requested scope |
| One answered card in a paused 23-card round | Resume | The second card is answerable and the first grade persists |
| 90 scheduled future cards | Open Review | The nearest due date and count are visible |

The live writers require the N191 trusted-receipt boundary. The public launch is controlled by the release PR after the integrated checks.
