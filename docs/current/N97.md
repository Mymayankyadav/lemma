## N97 — representative pre-v6 account upgrade rehearsal

A deterministic SQL fixture in tests/mcp/sql/fixtures/pre-v6-account.sql is loaded into isolated PGlite after every pre-v6 migration and before 20261105141000_v6_study.sql. tests/mcp/sql/upgrade-rehearsal.mjs then runs every subsequent migration from the checkout. It compares every legacy field that must persist in a representative path (subject, project, linked concepts and checkpoints), source pages, sessions and evidence, notes, FSRS card state and review history, and a pending proposal. New additive columns are allowed, but linked IDs, source text, scheduled due/recheck dates and history cannot silently change.

Historical session minutes remain legacy estimates: no measured study intervals are fabricated. Legacy reviews have no recorded FSRS parameter snapshot or scheduler version, so both must remain null rather than acquiring invented provenance. The test exercises authenticated owner export of legacy rows, edits and undoes a legacy note, creates a new study entry and task via audited commands, exports both and undoes both, then checks a second owner cannot export the account. It uses fictitious IDs only and never connects to the hosted database.

The test is a migration-level upgrade rehearsal, not evidence of a successful production deployment or a physical-device acceptance check.
