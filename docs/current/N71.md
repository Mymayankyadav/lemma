## N71 v6 Focus notices, parked thoughts and drift

With the existing default-off v6Shell Today Focus, an active persisted study entry exposes two independent actions. **Park a thought** opens a native, keyboard-cancellable dialog and saves the text using the existing owner-scoped parked-thought API, linked to that study entry, without changing its timer. **I drifted** records a positive whole-minute study event and explicitly does not deduct minutes until N66 provides that operation. An owner-filtered notice count comes from the study-events API and reloads with the entry; no estimated or invented count. Error and pending states remain visible and old Focus/flag-off code is unchanged. Regression coverage: tests/unit/focus/park-notice.test.tsx.
