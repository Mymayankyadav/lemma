## N71 v6 Focus parked thoughts, notices and drift

With v6Shell enabled and an active study entry, Today Focus now mounts a separate keyboard-accessible Park a thought dialog bound to the exact entry. It calls the existing owner-scoped ThoughtApi and never pauses or rewrites the study timer.

I drifted calls the existing StudyEventApi with a positive whole-minute duration. It records an event without deducting saved focus time; N66 owns any future deduction option. Notice, drift, and open parked-thought counts are rehydrated from owner-scoped paginated adapter records across remounts. All 50-row pages are read and exact totals and cursor progress checked. A failed read/write remains visible. No new server DML, timer write, dependency, or protected change is introduced.

Flag off or no active entry: no FocusEvents reads. The N71 park-notice unit tests cover pagination, count isolation, persistence across remount, errors, keyboard Escape, and flag-off behavior.
