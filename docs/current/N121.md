## N121 The 9 Nov 2026 v6 UI audit, fixed in one PR (Owner task)

Implements `docs/v6/ui-audit-2026-11-09/PLAN.md` for the findings in `docs/v6/ui-audit-2026-11-09/AUDIT.md`. Everything is behind `v6Shell`. Shared components (`Sheet`, `Toast`, `Editor`, `card/Page`, `proposals/Page`, `insights/Page`, `atlas/Page`) branch on the flag, so flag-off screens keep their old behaviour. No database, Edge Function, flag-default, protected-path or `docs/v6/screens/**` change, and no new dependency.

### New modules
- `src/lib/format.ts`: v6 dates, times, durations, intervals and zones ("Today", "Mon, Nov 16", "19:30–21:00", "1 h 30 min", "2 months"); `src/lib/text.ts` is unchanged.
- `src/lib/labels.ts`: human labels for planner reasons, session status, evidence, card and note types, study and practice ratings, tutor apps.
- `src/lib/focus/status.ts`: one focus status (`focusStatus`, `focusEntryStatus`) for the Today card, the dock and the Focus page.
- `src/ui/v6/Dialog.tsx`: native modal (bottom sheet below 700 px, centred above) with header, scrolling body, fixed footer, focus return and scroll lock.
- `src/features/calendar/grid/**`: elapsed-time Day and Week grids (DST-safe layout, overlap lanes, now line, tap to create, drag and keyboard move or resize with Undo).
- `src/features/calendar/views/AgendaView.tsx`, `views/labels.ts`, `deadlines/OverdueBanner.tsx`, `src/features/home/TodayDue.tsx`, `src/features/review/v6/estimate.ts`, `src/features/time-log/{local-time,interval-editor,relations,IntervalRowsEditor,StudyRelationsEditor}`.

### What changed, by phase
- **A Foundations.**
  - Sheets have a padded scrolling body and a fixed footer above the page header (z-index scale nav 50 < header 65 < menus 90 < sheets 100 < toasts 110). Transient sheets hide the nav and dock; only the New path route sheet keeps the five tabs.
  - Every sheet's primary action is in its footer (New and Edit card, Delete card, Inbox edit, batch confirm, Settings sheets).
  - Task, Block, Card filters, Planner, Time log add and Time log edit use the Dialog. Field errors are attached to their fields.
  - Header titles for Time log, Practice and Close the day; the ⋯ menu reaches Tasks, Practice, Time log and Close the day; Add → Time block opens the block dialog; `/kit` exists only in builds that allow flag overrides.
  - Single Inbox decisions wait 6 s with Undo; waiting single and batch decisions flush on unmount and `pagehide`. Toasts sit above the Inbox action bar.
  - One control language: disclosure chevrons, styled selects, gaps in action rows, one destructive style, one label style, token-coloured goal bars.
- **B Calendar.**
  - Overdue is computed against the owner's today, never the viewed range. One banner, with Done/Undo, Reschedule (new date, Undo), Open path, Practice now and Hide until tomorrow. Due details show names and formatted dates, never ids.
  - The block dialog has the eyebrow, separate Date, Start and End fields, a Study/Busy switch, length presets, Path, Checkpoint and Task links, and Delete on the left with a confirm. It opens at the tapped time or the next half hour.
  - Day: the time grid, a one-line summary (Free counts only the planning window), and an events list with Move, Done and Delete. The hour table and the always-open form are gone.
  - Week: seven fitted columns with lanes and ellipsised titles.
  - Month: activity dots, a logged-time tint, named cells and a collapsed conflict list. Saved focus inside a planned study block is no conflict.
  - Agenda: every day has a sticky heading, cards are tappable, overlaps are named and resolvable (Move, Shorten, Keep both), and a "Due today" chip leads.
  - The navigator names the range for each view, with chevron arrows; Planning tools is a two-item menu.
  - Planner: no slot before now, Date/Start/End pickers, sentences instead of reason codes, an automatic preview, and "Add N blocks to calendar".
- **C Today and Focus.**
  - Today shows today's calendar blocks without a day plan (three rows plus "N more", Start on the next study block), due-today and overdue rows, and Close the day after 17:00.
  - The review estimate uses real answer times (25 s a card without history).
  - Timer mode appears only for "No preset"; the duplicate captions are gone; "Aim for the day" replaces the second intention field; the watermark glyph comes from the linked subject.
  - The logged bar measures against Settings › Planning daily minimum.
  - Focus page: Finish & log is the primary action, Pause and Resume are outlined, Timer details is a disclosure ("Phase ends at", "Skip to next phase"), minutes to save are whole numbers, and the notice dialogs are left-aligned.
  - Close the day works without a plan (saved time, thoughts, tomorrow's first block, "Start a plan for tomorrow").
- **D Progress and Time log.**
  - One "Time range" control (Today · 7 · 30 · 90 days; old `day|week|month` URLs still work). One saved-focus total on Overview and on Time; range-matched Reviews, Recall and Checkpoints; tutor-session time is labelled on Learning.
  - A compact column chart (weekly for 90 days, no future days, empty state) and subject names.
  - Goals: friendly ranges, a separate Past goals list ("Reached" or "N short"), Edit plus a ⋯ menu.
  - Good and Easy have distinct colours, chart labels don't clip, tiles use sans figures.
  - Time log: a week navigator, one-line entries, interval summaries, Add time and Edit entry dialogs with pickers and named selects, a split picker, and a confirmed Void.
- **E Inbox, Plan proposal, Cards, Concept map.**
  - Inbox: one grouped Browse queue with rendered math and plain accessible names, project titles and "Session 7 · Checkpoint CP4" legends, a compact pager with Browse all, and no Inbox icon on the Inbox.
  - Plan proposal: "What changes" first, with the full plan under "Compare whole plan"; the draft editor only for live UUID proposals; sentences instead of validator text.
  - Cards: a meta line (N7 · path · checkpoint · due), a Sort control, a Checkpoint select in Filters, and human type labels.
  - Card detail: Delete under "More" at the end, "Pause card" / "Resume card", interval words, "Addressed by Claude", one preview.
  - Concept map: one concept/connection count, the legacy map header hidden in v6, visible status lines, at most 24 map arcs in v6.
- **F Remaining screens.**
  - Paths: one-path subjects shown directly; "3 of 12 checkpoints"; "Now: Compactness"; a popover row menu without "Close"; New path as a full-width row.
  - Path detail: Switch path opens the switcher; Next names the step; the forecast is omitted when unavailable; the tiles are the toggles; sources are listed once.
  - Checkpoint: prerequisites named, human evidence labels, one-line action hints, no "Back to path".
  - Session: formatted times, the checkpoint link once, no empty resume section, a Goal pill.
  - Review hub: Change opens Settings › Study & review, "Search decks" sits inside Decks & options, queue copy, "Show sub-decks".
  - Review round: one exit, a sticky four-grade bar with interval words and no check glyphs, and "No review in progress" for a direct link.

  - Tasks: overdue chips first and `?show=overdue`, a checkbox plus a ⋯ menu, a count only while more pages exist, refetch on focus.

### Waivers (with reasons)
- **G2 duplicate demo prompts.** The fixture is generated from a seeded random sequence; changing its prompt list regenerates every note number, review and due date that dozens of specs rely on. Only the wrong answer was corrected.
- **H1 side-rail navigation.** Out of scope for this PR, as planned; the tab bar is constrained to the content column instead.
- **Review 4 eyebrow.** "A SMALL SESSION, LASTING IDEAS" is in the mockup (`docs/v6/screens/review-*.png`), so it stays (decision D1).
- **Review round 1, nav during a review.** The release audit requires the five-tab bar on `/review/run`, so the grades moved into a sticky thumb-zone bar above it (decision D4).
- **Planner title.** The dialog stays named "Plan study tasks" (eyebrow "PLAN YOUR DAY"), not "Plan your tasks": `v6-release-audit.spec.ts` opens it by that name and must pass unchanged.
- **Activity option text.** Options keep "Proof workshop · pomodoro · 25 min" because the unchanged release audit selects that label; the repetition is removed by hiding Timer mode when an activity is chosen.
- **Block details sheet.** Tapping a block opens its edit dialog (time, links, Delete) rather than a separate details sheet; Start focus for a block is on Today's schedule. Move, Done and Delete are also in the Day events list.
- **C5 goal source.** The logged bar uses the Settings › Planning daily minimum; study goals have week or month periods, not a day.
- **D4 values on Checkpoints bars.** The shared chart component is also drawn by the flag-off Insights page; only colours, clipping and figures changed.
- **F7 leave confirmation.** Leaving a round from the header Back keeps the saved run, which Review offers to resume; no extra confirmation step was added.
