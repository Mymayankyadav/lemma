## N202 Rendered design checks

The rendered checks share a browser measurement helper with `npm run audit:ui`. The helper captures computed type, visible native controls, flow-text intersections, fixed chrome, and raw dates or versions. The fixture exercises a clean page and a page with every defect. The feature stylesheet scan checks fixed positioning separately.

See [the November 20 plan](../ui-plan/2026-11-20/NEXT-ITEMS.md) for acceptance criteria.
