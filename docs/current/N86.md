## N86 Atlas list pinning and safe graph impact preview (chat-94357#z6m2)

With `v6Shell` on, the Atlas list offers owner-checked map pin/unpin using the existing `LemmaApi.pinConcept` adapter. The dialog validates finite coordinates, shows the position, disables buttons while saving, reports RPC errors without dismissing, and refetches the Atlas on success. A separate read-only preview shows reasons to reject parent/prerequisite cycles and counts each hypothetical merge's children, incoming/outgoing prerequisites, and related links. No fake save occurs, synthetic groups are read-only, and flag-off Atlas is unchanged.

The Owner revised N86 in rules PR #1150: create/edit/reparent/link/unlink/merge need the not-yet-exposed owner command and are now N105. This PR adds no browser SQL, unsupported mutation or new dependency. Tests cover cycle checking, impacts, pin success/failure, and read-only preview. CI controls merging.
