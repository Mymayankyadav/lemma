## N86 Atlas editing in the v6 list (chat-94357#z6m2)

Current work adds pure Atlas editing safety checks for proposed parent and prerequisite links and an explicit merge-impact count. It refuses self-links, unknown records and cycles with an actionable reason. The checks do not mutate backend state: the server must still be the authority for writes. The v6 list now uses only the existing owner-authorized `pinConcept` API for map pin/unpin with a guarded keyboard dialog, finite numeric coordinates and visible RPC failure feedback. Remaining N86 work is owner-authorized create/edit/reparent/link/unlink/merge: no such methods are currently exposed on `LemmaApi`, so these must not be simulated as successful browser writes; an API/scope contract resolution is required before claiming Done. This PR is WIP, not Ready or deployed.
