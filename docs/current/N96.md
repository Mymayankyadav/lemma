## N96 reversible v6Shell rollback journey

The one end-to-end test creates a real saved Focus interval, one calendar block and one task through the demo UI while v6Shell is on. It verifies the three durable sessionStorage records, switches the shell off without clearing the tab, walks all 18 canonical legacy routes and checks that they load without page exceptions or v6 shell chrome, then turns the shell back on. Focus logged minutes, calendar block and backlog task reappear in the UI; the complete snapshots (including record IDs) are unchanged across the off/on cycle.

The test uses the same browser tab and demo adapter, so it tests flag rollback rather than sign-in/export behavior. It includes the real 390-pixel viewport and blocks decorative external font requests to keep CI independent from third-party network. No application, database, migration or feature-flag behavior changed.
