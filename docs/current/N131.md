## N131 v7 UX audit r3: the rest of U0 (truth) (12 Nov 2026)

With N130 (V02, V03, V17, V24) and N125 (V01, V04), every U0 finding of the v7 UX audit r3 is now fixed. Each is ticked
in `docs/v7/ux-audit-2026-11-12/CHECKLIST.md` and has a check in `tests/e2e/v7-n131-truth.spec.ts` or
`tests/unit/v7/n131-truth.test.ts`.

- **V14 Dock.** Capture faded out on scroll but kept its slot, so the bar was lopsided. It now stays (it lives in the
  dock row); the row has the same inset at both ends, so tabs plus Capture are centred within 1 px.
- **V15 Calendar Month.** Heat step 2 took the primary ink (2.93 : 1 by day, 2.97 : 1 at night). It now takes the page
  colour, like steps 3 and 4 (5.4 : 1 and 5.7 : 1). Every step is ≥ 4.5 : 1 in both themes.
- **V16 Almanac.** `heatmapDays` (`src/ui/v7/Chart.tsx`) keeps the days from the Monday of the first study day's week
  (with no study yet, the last four weeks), so it no longer draws six months of empty cells. The single tab stop starts
  on today, and the scroller opens with today in view.
- **V18 Names, not codes.** The checkpoint page's collapsed header is the checkpoint's title (was "CP4"); plan-proposal
  rows read "stage · state" (was "CP1 · Foundations · …"); path cards and the "due" list name checkpoints by title; the
  tutor's reasons go through `nameCodes` (`src/lib/codeNames.ts`): a checkpoint code becomes its title (else
  "checkpoint 4a") and a session code "session 6".
- **V32 Not found.** With v7 on, an unknown address shows `NotFoundV7` ("This page isn't in the notebook.", with Search
  and Go to Today) inside the v7 shell, instead of silently showing Today. The catch-all route carries
  `handle: {notFound: true}`, which `AppShell` reads. With v7 off it still goes to Today.
- **V33 Example deck.** Linear Algebra's 30 cards all sit on Diagonalization and Topology's 12 on Topological spaces,
  and each had two prompts, so the library showed the same two cards over and over. `src/data/demo/math-prompts.ts` now
  has 30 and 12 distinct, real prompts there; `fixture.json` was regenerated with `npx tsx scripts/make-demo-data.ts`
  (only the fronts and backs of 38 cards changed). Real Analysis still repeats a few cards further down the list.
  The new cards exposed a review bug: a mouse swipe that started on text the previous swipe had selected dragged that
  text (the browser's own drag and drop cancelled the gesture), so the card never graded. `ReviewRoundV7` now clears the
  selection when a mouse swipe starts and after a swipe is read; the existing "all 23 seeded cards with swipes" test
  covers it (it failed on card 21 before the fix).
- **V34 Copy.** Reminders say "Times are in India Standard Time" (`zoneLongName`); subject rows read "Analysis · ∫"
  (no "glyph"); the Tutor sessions tile shows only the duration; chart sentences use the exact duration
  (`totalFormat`: "1 h 35 min", not the axis's "1.6 h") and say "Nothing studied in this range yet." for zero; the card
  editor's key row starts with fraction, sum, integral and set braces, and a LaTeX preamble line now names the macro it
  defines (`\R`, `\tr`), never `\newcommand` or `\DeclareMathOperator`.
- **V35 Cloze.** In v7 the highlight uses the selection tint and ink (7.4 : 1 Day, 8.3 : 1 Night); the legacy amber
  resolved to the danger red there.
- **V37 Inbox triage.** Reject, Edit and Approve are one size (56 px) on one line, so their labels share a baseline.
- **V38 Card detail.** The Next review date stays on one line (its size follows the screen width). When the card is due,
  the pinned primary is **Review now** (the card's path in Review, which includes it); "Edit card" stays in the bar as a
  secondary button, because an existing §6.11 test requires it there; Pause and Resume are in the ⋯ menu.
- **V39 Sign-in.** The links and the note sit on the page colour with an 8 px margin, so the construction drawing passes
  behind the title only.
- **V40 Session.** "Resolved" read as a status; the button now says **Mark resolved**.
- **V42 Calendar.** Days outside the month have no frame and no heat, in secondary ink. Week blocks on a phone show the
  title's first two words (`weekShortTitle`) from a 40 px block (a day column is 42 px at 390 px; the plan said 44);
  from 600 px the whole title, as before.
- **V43 Data and account** (`src/features/settings/v7/DataAccount.tsx`): three grouped lists in the kit's sizes —
  Account (sign out), Export (one row, one sentence, one button: "Download a backup", or "Save a backup" in the app) and
