## N241 Exam prep on a Path

`examMode` is off by default. In a dev or test build, open a v7 Path with `?flags=examMode`. Choose **Prepare for an exam…** from its actions. Setup saves a sitting and a Calendar exam deadline. The Path shows the next course step and the next exam action. The Exam tab includes the coverage ledger, planner recommendations, evidence, exposed marks and compulsory conflicts. Pin a row, skip it with a reason, or defer it with a reason and a reopening condition.

Once the exam start time passes, the app asks whether the exam took place, enter a new date or defer the prompt for six hours. Planning settings can set the default card mode for future sittings. The Tutor action pre-fills an exam-specific question in the existing Tutor. A draft or scored response still depends on the user's connected tutor.

The app and MCP share the planner and use the same bounded, subject-scoped evidence lookup. Exam snapshots stay within the existing five-Path offline cache and support reading only. Uncertain writes replay their operation IDs. The app retries a version conflict once after refreshing the sitting. Setup stores retry state for the current browser tab so a lost Calendar acknowledgement can be recovered without making another sitting. Demo includes planned, active and finished sample sittings.

The browser spec covers setup, mode switching, ledger evidence, dispositions, compulsory conflicts and passed-exam actions. It checks three viewport sizes and attaches light and dark ledger captures to the Playwright report. The adapter tests cover receipt replay, stale versions, offline writes and Calendar recovery.
