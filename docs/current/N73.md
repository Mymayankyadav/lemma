## N73 v6 time log for corrected and approximate saved study

Behind v6Shell the lazy /log route shows the existing owner-scoped StudyApi records in a selected seven-day owner-time-zone range, grouped by civil date with bounded 50-row client pages and each saved interval shown. It exposes edit of intent, rating, optional links, reflection and the full interval set, split at a selected ISO instant, and void/restore. All writes use existing N65 owner-versioned commands and refresh the server-authoritative list after success. A separate form creates explicitly approximate manual saved time via createManualStudyEntry. Unknown ratings remain unknown. Export emits quoted/escaped CSV rows for all records in the visible seven-day range, with each interval represented separately.

Flag off redirects to Today and performs zero study reads. No new data adapter, direct table mutation, migration, dependency, or protected-file change. Calendar and Progress continue to read authoritative StudyApi after refresh. Tests/unit/time-log covers flag isolation, civil ranges, paging, edit, void/restore, manual validation, CSV escaping, and unknown ratings.
