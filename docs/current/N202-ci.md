## N202 browser regression corrections

The fast gate on `5c4cd7b` exposed gaps beyond the earlier Atlas-focused verification. Local reproduction also found older Calendar and Tutor checks still using controls the owner had moved into menus, and an Atlas framing regression in the broader UI-plan suite.

Atlas's native sheets now opt into explicit forward and backward Tab containment. Escape in a nested picker closes that picker and restores its opener without also closing the parent form. The option rail keeps its transparent background and translucent buttons; its width no longer shrinks the initial map framing. Toggling the rail preserves the camera. Existing map coverage, zoom, selection and gesture assertions remain unchanged.

Progress and Review mount chart and memory content when their detail sheets open. This avoids hidden duplicate chart controls and zero-size chart work while preserving the disclosures. The optional `v7Room` Learning view retains its Learning heading; the default Progress header and the revised grade colors remain unchanged. Path actions use the smaller shared horizontal spacing at narrow widths, keeping the full Continue with tutor label and the kit button height.

The final responsive review also found two readability defects. Chart axis gutters, tick density and goal annotations now follow the actual caption size, keeping enlarged labels inside the plot and clear of each other. A hidden size probe responds to font changes without polling. The Path goal preview now leaves room for its disclosure arrow and uses an ellipsis; opening it exposes the complete goal. New browser assertions check the enlarged chart labels and both narrow goal disclosures.

First-use demo study entries, calendar blocks and goals use their own empty storage namespaces. Adapters remain bound to the profile they opened, and switching profiles preserves each profile's saved records. Populated demo history stays available. A new regression creates records in the first-use profile and verifies both profiles after switching back and forth.

Calendar tests now reach Choose date as the fourth Calendar actions item. They retain date changes, return to today, selected-day state, the seven-day grid and narrow layout constraints. The Tutor quota test reaches Context through Edit answer → Answer actions and retains its original storage warning and recovery assertions. No test thresholds, budgets or CI configuration changed.
