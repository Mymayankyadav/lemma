## N125 Fixes from the Owner's phone report (12 Nov 2026)

The Owner tested the first Android build (2.0.592) and the v7 screens and reported six problems. Each is fixed here
with a regression test.

| # | Report | Cause | Fix |
|---|---|---|---|
| 1 | "ℓ looks off centred" (Today header) | The mark was an italic text glyph; its font metrics sat it high and left in the 28 px tile. | `EllMark` (`src/ui/v7/marks.tsx`) draws the app icon's own optically centred ℓ path (`scripts/brand/lemma-mark.mjs`, `simple` layout) in the header tile and the desktop rail. Test: `brand-mark.test.ts`. |
| 2, 3 | "Can't press any of the buttons" (Settings › Reminders › On this phone); "No notifications in the Android app" | Every call to the app's own plugin failed. Capacitor's plugin proxy answers every property with a native method, `then` included, so `lemmaNative()` (a promise resolving to the proxy) treated it as a thenable and called a native `then()` that does not exist. So no permission prompt, no timer notification, no reminders, no Study mode or calendar, and the rows did nothing. | `notThenable()` in `src/platform/bridge.ts` hands out a view without `then`. A first running focus session now also asks for notification permission once (the lock-screen timer needs it). The rows show "…" until the status loads instead of a guessed "Not asked yet". Test: `tests/unit/android/bridge.test.ts` (hangs on the old code). |
| 4 | "The buttons look congested" (Settings › Tutor) | Three small buttons in a wrapping chip row. | A two-column grid: Show and Copy side by side, New address full width below. |
| 5 | "This awkward highlight bar appears in almost all charts" | Not ours: the WebView's default focus ring on a tapped column (tapping focuses it). | No outline for taps; the selected column is a faint band; keyboard focus keeps a focus-ring stroke on the band. |
| 6 | "Why everything is 0 mins" (chart axis) | The labels were right but clipped: "20 min" and "40 min" lost their first characters in a fixed 40-unit gutter. | The gutter fits the widest tick label. |
| 7 | "Awkward placement of the buttons" (Edit time block) | Delete, Cancel and Save changes did not fit one row, so Save wrapped below. | Kit rule R1 · F17/F39: the footer has Cancel and Save on one row; Delete is the last item of the sheet body (its confirm step is unchanged). |

Found while checking: a selected filter chip showed two ticks ("✓ ✓ 50 min"): the kit's CSS draws one and `Chip` added a
second `<Check/>`. The component's copy is removed.

**Android:** the native fixes reach the phone with the next `Lemma.apk` on GitHub Releases (built when this merges).
After installing it, Settings › Reminders › On this phone › Notifications asks for permission, and starting a focus
session asks once too.
