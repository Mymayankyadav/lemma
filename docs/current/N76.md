## N76 — Progress goals and exact ranges

The v6 Progress view now offers true rolling 7, 30 and 90 owner-civil days (inclusive of today), alongside its existing Day/Week/Month controls. The same effort engine accounts only for saved focus intervals and clipped calendar boundaries; charts expose true per-day values instead of rounding each day to a whole minute. Subject amounts use hundredth-minute remainder allocation so the displayed partition sums to the displayed saved total.

The StudyGoals panel uses the merged N59.2 demo/live API for bounded goal pages and optimistic create/edit/archive; it displays current saved minutes against weekly, monthly or custom goals for each goal's own IANA zone and inclusive dates with exact subject/project filters. The chart range and the visible goals share one encompassing owner StudyApi read (rather than N extra reads per goal), with a retryable error and no invented data. Flag off remains unchanged because the existing Insights flag branch owns the ProgressV6 mount.

Unit regression: tests/unit/progress-v6/goals.test.tsx checks 7/30/90 civil windows, DST boundaries, scope and period clipping, exact subject partitions, and goal lifecycle controls. No schema, flag default or other data module changed.
