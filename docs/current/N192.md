## N192 Offline Local Pad

Local Pad opens from a v7 checkpoint under the `padLocal` build flag. Live entry also requires the shared `lemma_plan_released` response and a checkpoint returned for the current authenticated owner, project and generation. A stale result disappears on account change. The isolated demo keeps a separate IndexedDB namespace for each fixture profile. The deployment default remains off until the shared launch.

The graph-paper textarea supports the native keyboard, composition, caret and selection, deterministic symbols, explicit template slots and local TeX command suggestions. Bundled KaTeX renders HTML and MathML with isolated macros and finite input, formula, expansion, dimension and output budgets. Prose and unsupported formulas stay literal. The fixed 640 × 400 ink surface preserves completed strokes across rotation, offers Draw and Scroll modes, cancels interrupted strokes and can undo a clear.

Each owner has a separate IndexedDB database. A checkpoint keeps its latest and previous draft, including selection, up to 65,536 UTF-16 code units of text and completed strokes. A save checks the expected revision inside the write transaction. A conflict, unsupported version or failed write keeps the working copy available for export. A valid previous revision can recover a corrupt head. The editor previews a previous draft or a bounded portable JSON backup before replacing the working copy. Save draft commits that replacement. Putting the Pad away retains unsaved work in the open checkpoint.

Opening an online verified checkpoint records the owner and checkpoint bookmark, the installed entry asset and the server-issued session identifier for the active sign-in. The device-only link can cold-open the saved Pad from precached assets, including after the access token expires offline. It compares the owner's stored session with the recorded identifier before each storage operation. Another sign-in, account, build or a confirmed closed release needs fresh online authorization. The receipt grants access only to saved local Pad data. No credentials, note content or ink are written to the receipt. The shared application sign-in and server permissions govern all network operations.

Export Pad backup creates portable JSON. Export readable Pad produces a standalone HTML document containing escaped notes and vector ink. On Android, the app opens the existing system share sheet with the JSON or HTML MIME type. A late callback checks its owner again before sharing. Switching accounts or signing out revokes the prior file grant and clears the temporary app-cache copy. Settings backup includes this owner's current and previous saved revisions on this device. The Pad data is added in memory after downloading the account record. A rejected account deletion retains the drafts. A confirmed deletion clears the matching owner's database and device markers and preserves other accounts' data. Account switching during the request protects the new account from sign-out or cleanup.

The checkpoint host exposes only the selected nonblank text, up to 1,200 UTF-16 code units, in response to Send selection to tutor. The P6 integration opens its preview, preserves leading and trailing whitespace exactly and requires Add local excerpt before Save question. Later Pad edits leave the submitted text intact. The standalone offline editor supports local work and export.

Chromium exercises disconnect, two cold PWA reloads, a disconnected edit, native text selection, checkpoint and owner isolation, portrait-to-landscape ink, JSON import and HTML download. Mock live endpoints exercise the authenticated adapter and release gates without contacting a real account. Tests also cover account backup and deletion, IndexedDB failure, IME, corruption, conflict and the Android share bridge. The Java export MIME and filename tests run on the host JVM.

The remaining physical gate is a POCO M8 Power running Android 16. It requires the installed app, airplane mode, soft keyboard and rotation, then an Android file save and re-import. No physical run has been recorded.
