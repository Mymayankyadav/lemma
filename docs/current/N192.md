## N192 Offline Local Pad

This is the first, unmounted P8 slice. `LocalPadEditor` is a controlled graph-paper textarea with native editing and composition, caller-owned text and selection snapshots, deterministic symbols, explicit template slots and local TeX command suggestions. The preview uses the repository-pinned KaTeX with only bundled assets, isolated macros, HTML and MathML output, and finite source, formula, expansion, dimension and output budgets. Prose and unrenderable formulas stay literal; Markdown does not become a link or embed. There is no transport, provider, route or flag change. Review ScratchPad is still ephemeral.

The host adapter should bind `PadEdit` to the verified `authOwner()`/`authGeneration()` boundary and the authorized `CheckpointDetail.view.id`, not the email-only `useAuth()` result or route slugs/codes. Key the editor by that binding, discard late loads on scope changes, and keep editor state responsive while storing revisions off the typing path. The existing AND-8 offline cache is a redacted, expiring query snapshot, not a draft store. Wait for P1/P3’s storage and offline authorization contract before mounting or creating durable records. Await P6 before reviewing and freezing selected-only context for a send.

Still pending: transactional draft/stroke recovery and truthful failure state, ink and rotation, export, a default-off entry, selected-context review and send, and end-to-end airplane-mode reopen and real-device keyboard checks. The standalone editor tests cover selection, composition events, MathML, limits and no local-edit fetch; they do not verify those integration gates.
