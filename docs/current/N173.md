## Atlas v3 MCP contract first pass

`mcp/atlas.ts` loads new facts and serves profile, theme(s), bridges, probes, model health, card budget, plan template and conversion input. Migrated reads use the shared `assembleAtlas`. `save_progress` validates structured attempts before writing and rejects them before cutover with `Atlas v2 not migrated`; explanations can carry `concepts[]`.

The existing atomic RPC remains the transaction boundary. New SQL branches store attempts and tags and leave legacy evidence frozen after activation. Same-save duplicates merge, and an invalid later tag rolls back the entire save. Stage metadata is accepted as passthrough input without advertising a large new tool schema. The existing tools/list size test remains in force.
