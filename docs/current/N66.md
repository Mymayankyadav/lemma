## N66 StudyApi timer modes, phases and lease (chat-59731#z4q8)
N52 merged, so both adapters now expose the additively typed server-captured mode, preset, immutable config, phase, cycle, energy, exclusion and lease fields. The live adapter uses the owner-JWT study_command N52 envelope for take_lease, next_phase and exclude_minutes, with a tab-scoped random device token, explicit lease generations and visibility-gated two-minute renewal. No owner ID, fake client clock or direct writes to server-managed timer fields. An optional preset is applied to a draft via its owner-RLS row before audited start.

The demo adapter captures an active preset or safe open defaults on start, uses a tab-local lease, models Pomodoro / Flowtime / open phase transitions with server-shape deadlines, and subtracts reasoned focus minutes from non-overlapping free focus spans. Both preserve old lifecycle and saved-entry APIs. N66 remains guarded by the Study API unit tests and PR CI; no server schema or UI change.
