## N202 owner revision and mobile math input beta

The owner continued PR #1738 after rejecting its original visual comparisons, then added mobile proof input to the same PR. The release adds a Settings beta for single symbols and keeps the custom keyboard with a direct symbol-recognition button. N200 remains the separate full-equation recognition task. [November 21 specification](../implementation/2026-11-21/mobile-math-input.md)

Settings → Tutor → Math input beta offers **Draw single symbols**, off by default and scoped to the current owner. Its **Automatic insertion when qualified** preference is separate. The shipped model lacks a qualified calibration artifact, so every recognized or completed symbol requires an explicit tap even when that preference is selected. Disabling the beta, changing owner or checkpoint, composing with an IME, clearing ink or changing the editor target invalidates pending work. Session recents are transient. Persisted preferences participate in the existing owner deletion boundary.

The custom keyboard and manual catalogue remain available without recognition. The catalogue contains 153 canonical symbols and supports local search by name, TeX command or common shape description, with typo tolerance. Insertion uses Unicode in prose and checked TeX inside explicit math. Deterministic completions finish started words, offer exact aliases or reformat fully supplied declarations. The learner supplies every mathematical choice. The same policy applies with the beta off, and recognition runs locally.

The dedicated symbol pad preserves drawing feedback while its local worker prepares. One compact row shows up to three matches and three compatible extensions, with a spinner while loading and accessible group labels. A glyph eligible for both groups appears as a possible extension. A candidate tap checks the displayed choice against the current session, ink revision and editor target, then creates one undoable edit. The automatic policy also requires a genuine completed-stroke receipt. Geometric choices remain available if the classifier fails. Interrupted gestures and rejected edits preserve unresolved ink.

Detypify 0.3.0 weights and metadata and ONNX Runtime Web 1.27.0 are pinned and licensed. A versioned manifest verifies model, metadata and WASM bytes before the single-thread worker reports ready. Web assets load lazily, verified assets survive an offline restart, and the Android-mode build packages the same files locally. [Runtime measurements, provenance and remaining qualification](../../public/models/tutor-symbols/detypify-0.3.0-lemma-v1/README.md) distinguish desktop browser results from unmeasured physical phones and installed WebViews.

The picture scratchpad saves editable drawings before inserting inline references at the caret. Repeated transitions between typing and drawing preserve composition order in the editor, transcript and authorized MCP handoff. [Scratchpad parity](../ui-plan/2026-11-20/scratchpad-parity.md)

Atlas keeps Back separately visible and groups its options in one transparent vertical rail with individual translucent glass buttons. Subject shortcuts sit below the map controls; the top eye button shows the options and the crossed-out eye hides them. Search expands in place; narrow results put the subject below the concept name so the name can use the result's width. List covers the map, pauses canvas rendering and stops pending layout work. Both List and concept details hide bottom navigation. Closing a layer restores the preceding view and its controls. Prior filters and edit actions remain available.

Tutor keeps the header anchored as the custom keyboard opens, with a side-by-side transcript and keyboard on short landscape screens. Calendar hour labels fit at enlarged text sizes, and Week suggestions use a centered plus with the full accessible action label. The shared dock shows icons and the active label when space is tight. Path tabs and its primary action wrap, and Undo stays above the visible split footer. Review card text and the selected Teaching style use readable Day-theme colors. Deleting a library card offers Undo to restore its previous active or paused status. `todayNextStep` and `tutorScratch` retain their existing default-off release flags. The beta opt-in works with the picture scratchpad flag off. Owner visual acceptance and independent review of the PR's existing migrations remain outstanding. The requested candidates-only beta can proceed without owner device testing.
