## N156 One meaning per glyph, one line weight (IC1, IC2, IC3, IC5) (13 Nov 2026)

P6 of `docs/v7/ux-audit-2026-11-12/06_ILLUSTRATION_ANIMATION_ICON_AUDIT.md`. Owner decision E21 (13 Nov 2026): 1.75 px
at every size, one meaning per glyph, six new drawn marks.

**One line weight (IC2, IC3)**
- **Was:** the line drifted with size, from 1.17 px (14 px icons) to 2.33 px (the 28 px tick). That was lucide's
  2-unit stroke scaled with the icon, beside the drawn marks at 1.75 and the grade glyphs at 1.6 on a 16-unit grid.
- **Now:** every `svg.lucide`, `svg.v7-mark` and `svg.v7-grade-glyph` in v7 has `stroke-width: 1.75` and
  `vector-effect: non-scaling-stroke` on its shapes (`kit-system.css`). The line is therefore 1.75 CSS px at any size.
- **Why CSS, not only the provider:** the plan named `LucideProvider absoluteStrokeWidth`, but that works from the
  `size` prop, and v7 sizes most icons in CSS. So the rule is held in the stylesheet.
- The kit page no longer sets 1.5. The grade glyphs are redrawn on the 24-unit grid, and the drawn marks carry
  `v7-mark`.

**One meaning per glyph (IC1, IC5)**: `src/ui/v7/meanings.ts` (`MEANING_ICON`) is the one table the screens use.

| Meaning | Was | Now |
|---|---|---|
| Review, cards due | Layers | Layers (its only job) |
| A card (Search's Cards, Capture's card) | Layers | `CardMark`, one card |
| Practice due (Today, Calendar Day, Agenda) | Layers, Target | `PracticeMark`, ∫ on a card |
| Switch path | Layers | `ArrowLeftRight` |
| Concepts, View in Atlas | Star, Waypoints | `ConstellationMark`, three stars |
| Checkpoint | Target | Target (its only job) |
| Target date (meta chip) | Flag | Flag (its only job) |
| Deadline (Calendar Day, Agenda, Month) | Flag | `DeadlineMark`, a calendar with "!" |
| A task, a block's task link | CheckSquare, Flag | CheckSquare |
| Changed | Triangle | `ChangedMark`, ± |
| Suggested | Sparkle | `SuggestedMark`, a dashed square with + |
| Study settings | Brain | `BookOpen` |

- The six new marks share `marks.tsx`'s grid and line. The Inbox's "Show the stack" uses `GalleryVerticalEnd` (a stack
  of cards), not Layers.
