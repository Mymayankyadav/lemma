## N243 Return from exam prep

The Path shows a return card for three days after a pause and fourteen days after finishing. It displays the course bookmark and prioritizes the current checkpoint if the plan moved. The shared comparison finds rows whose latest evidence improved since activation and maps them to course checkpoints or concepts.

The Path’s Cards tab includes saved ideas. The learner can draft a proposal, link an existing card, postpone a decision, revise the idea or dismiss it with undo. Drafted ideas link to Inbox and show the linked card after approval.

Today reads the countdown, passed-exam question and return card from the combined Home response. After a finished exam, a Path whose course horizon passed offers an explicit new course date or archive confirmation. Calendar continues to use the owner’s exam deadlines and conflict-aware study blocks. Practice offers checks and recaps on high-exposure topics, and Review can start a smaller due-card round within the learner’s existing budget. These actions do not submit a card rating.

Exam reminders have separate opt-in controls on the server delivery settings surface. Both default to off. The demo browser specs cover the separate tutor conversation, return, proposals, Calendar after reload, and Today and Practice handoffs.
