## N235 Grammar and LaTeX inside equations (flag `typeaheadV2`, default off)

- **LaTeX model** `public/models/typeahead/latex-v1/ngram.bin` (444,412 bytes): a Kneser-Ney trigram over LaTeX tokens of Math StackExchange
  spans (`python3 scripts/typeahead/build-latex.py --input proofpile_dev.jsonl.gz`); a single letter is the class `<latin>`, digits `<num>`;
  held-out perplexity 9.2. Loaded with the n-gram (`prepareTypeahead`).
- **Automaton** (`writingAid/latexGrammar.ts`): a pushdown automaton over the maths typed so far tracks open `{ ( [ \left \begin` and the arguments
  a command still wants (`\frac` 2, `\sqrt`, `\mathbb`, `^`, `_`…). `latexAllows` can only remove tokens: no closer without its opener, no relation
  after a relation, no script at the start of a formula or after an operator, an argument due means `{` (or one atom for a script).
- **Strip.** Inside an unfinished `$…` the three slots show the next LaTeX tokens (a symbol shows its glyph, else its LaTeX). `<latin>` is filled
  only from variables the learner or question already uses. A tapped token replaces the command being typed; `{` inserts `{}` with the caret inside.
  A `\name` being typed still gets the symbol suggestions of N221 first.
- **Prose** (`writingAid/grammar.ts`): "a" before a vowel sound and "an" before a consonant sound are removed; a word that starts a sentence is
  capitalised; after a singular determiner (a, an, this, each, every, one, another, any) a plural noun is dropped. Class-based back-off is in the
  model: single letters, numbers and unknown words are the classes `<m>`, `<num>`, `<unk>`, so an unseen context falls back to its class.
- **Not done:** a fourth-order LaTeX model, `\begin` environment bodies beyond the stack, suggestions inside the Equation sheet's own LaTeX field,
  and the unit and e2e tests.
