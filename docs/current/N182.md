## N182 Atlas v3 screens on by default

`atlasV3` in `src/flags.ts` now defaults to on. After the Atlas v3 activation (docs/current/N180.md step 8) the legacy screens read evidence that no longer changes, while the Atlas v3 panels (model health, facets, link proposals, Atlas settings, filters, slot suggestions) read attempts; this release is step 9 and merges only after step 8. Production builds ignore overrides, so the rollback is a PR setting the default back to false (no data changes). In dev, test and e2e builds `?flags=-atlasV3` shows the off path.

Test changes: `tests/unit/flags.test.ts` lists `atlasV3` among released flags (as earlier releases did). `tests/unit/adaptive-ui/parity.test.ts` removes the demo's Atlas planning window (which the demo adds when `atlasV3` is on) from its fixture, so the test keeps checking the capacity override it sets itself; every assertion is unchanged.
