## N98 — v6 first-slice hardening: Today, Focus, time log and Progress

The Today/Focus pair now reconciles the active owner StudyApi entry and saved effort on window focus and visibility restoration. A changed entry version invalidates local lease ownership; the server remains authoritative for all versioned writes. Starting a verified committed block in the adjacent Today plan immediately tells both Focus and the shell accessory to refresh, then opens the same session instead of leaving a stale Start surface. No second browser timer or duplicate study record is created.

The persistent Focus accessory discards superseded asynchronous reads, clearing an earlier error after a successful owner refresh. Its actions wrap at narrow widths and 200% text; the full intention remains accessible, while the v6 native Focus dialog wraps long uninterrupted mathematics without horizontal overflow. The time-log entry intent, interval instants, editor IDs and page controls wrap or stack for phone widths. Progress daily bars, subject labels, goal details and goal date inputs likewise reflow under large text. All changes are scoped to v6 surfaces or responsive presentation and preserve flag-off pages.

`tests/e2e/v6-harden-slice.spec.ts` exercises 320/360/390-pixel viewports, explicit Day/Night palettes at 200% root font size, focus dialog Escape, 44-pixel controls, long unbroken mathematical intent, manual saved-time appearance in Progress, accessory/dock geometry, reload with explicit lease takeover, back navigation, three-hour advisory and flag-off isolation.

Intentional limits: an isolated browser demo tab stores its own session snapshot, so the e2e suite verifies reload/restore and authoritative version UI rather than claiming a real multi-device Supabase integration test. iOS/Android hardware Back, physical-device screen readers and OS-level native timers remain outside this web-only task. Browser tests require CI's Playwright environment; no local browser runner is available in this session.
