## Atlas v3 link pipeline first pass

Adds deterministic trigram/blurb/neighbour candidates, content hashes, rejection suppression, exact-name/same-parent automatic equivalents, label validation, 40-decision approval-rate throttling, default prerequisite/technique tags and bridge-strength helpers. Worker output is explicitly reduced to allowed suggestion fields; results, hints, errors and cues are never accepted from it. React has link approval/rejection controls.

The worker model remains injected and dormant, consistent with the absence of a worker API key. Remaining: nightly/import orchestration, real opportunity/usage aggregation, batch-kind approvals and complete proposals UI acceptance.

Second pass (chat-91357): bridges now carry real strength. `bridgeCounts` (06 §5) counts, per link source A, the uncued attempts in another subject whose solution uses A (A tagged required or incidental) as opportunities, and the ones where A was used correctly as uses; `assembleAtlas` feeds them to `bridgeStrength` (it was called with zeros, so every bridge was dashed). Tests: `tests/unit/adaptive/links-bridge.test.ts`. Still open: nightly and import orchestration of the link pipeline (the worker model stays injected and dormant without an API key, and a schedule belongs in a protected workflow or cron migration), batch-kind approvals and full proposals UI acceptance.

Orchestration and batches (chat-91357): `nightlyLinkBatch` (workers.ts) is the import and nightly run: only concepts that are new or whose name/blurb hash changed are fresh, each is compared with the others, at most 50 proposals per batch with the rest reported as deferred, rejected pairs return only after a hash change, and exact same-named pairs link automatically. It takes the injected label model, so it stays dormant without an API key; the schedule that calls it is a protected workflow or cron change for a `rules:` PR. Link proposals are shown grouped by kind with "Approve all N kind" and "Reject all N kind" beside the per-link buttons (`groupProposals`). Tests: `tests/unit/adaptive/links-pipeline.test.ts`, `tests/e2e/v7-atlas-v2.spec.ts`.
