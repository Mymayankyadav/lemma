## N95 account export — registry-backed owner-only read path

An Owner-authorized read-only SECURITY DEFINER RPC, lemma_export_page, reads the private lemma_undo_tables registry and exports only authenticated caller rows (user_id = auth.uid()). Its registered-table allowlist, catalog-quoted primary-key identifiers and stable JSONB keyset pagination support composite and non-UUID keys in 100-row batches. The function cannot be executed by anon or service_role and grants no browser access to the registry itself. It redacts connector_secret before data reaches the browser.

LiveAdapter.exportAll now discovers all registered names through the RPC, traverses every owner table with cursor-based pagination, and creates a versioned lemma-backup-v2 manifest of tables and exact counts. It keeps archived rows, validates every returned owner, rejects malformed responses and stale cursors, and redacts connector credentials again before writing the backup. The unit suite tests dynamic future registrations, >1000 rows, >100 resources, owner separation and malformed pages. The PGlite integration test verifies role permissions, owner RLS equivalence and keyset behavior.

The migration remains unapplied until CI completes, an independent migration reviewer approves, and the Supabase deploy succeeds.
