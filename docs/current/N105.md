## N105.1 Atlas command core and split

N105 exceeded the 800-changed-line threshold once an audited owner command, graph merge/undo/MCP SQL tests, demo/live data adapters, and interactive Atlas editing were included. This first, hardest slice owns the database write path and leaves the UI/API facade work to N105.2.

The additive SQL migration creates the owner-checked, operation-ID receipt-backed concepts_command registry endpoint. Create, rename/blurb update, same-owner reparent, prerequisite/related link and unlink, preview and merge perform optimistic version checks, and every accepted mutation changes the action journal. The prerequisite guard rejects cycles regardless of the calling path. Merge previews reference counts before mutation, moves child concepts, graph links, checkpoint links, note/card references, misconceptions and practice-topic references before removing the source, then increments the kept concept's version. Database undo uses the registered concepts and graph relation tables. The authenticated RLS owner and service-role MCP dispatcher share one command signature.
