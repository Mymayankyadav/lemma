## N127 A2 Empty-state illustrations (12 Nov 2026)

The Owner chose the illustration style from three samples (D6 = **A · Notebook line art**) and asked Claude to draw them
(D8). `src/ui/v7/Illustration.tsx` holds the eight drawings of the plan, each a small code SVG (about 1 KB, budget
12 KB): one ink weight with round caps, muted secondary lines and a single accent: the subject colour where the page
has one (`--v7-subject`), else the brand indigo. Every colour is a theme role (`illustration.css`), so Day, Night and
forced colours follow; the drawings are decorative (`aria-hidden`), the empty state's text carries the meaning.

| Id | Where | Drawing |
|---|---|---|
| IL-01 | Paths, no paths yet | a blank notebook page with a compass about to draw |
| IL-02 | Calendar Day, nothing planned | an empty day under a ruler, a dashed block where study could go |
| IL-03 | Review, nothing due | a squared deck with ∎ and a tick |
| IL-04 | Inbox zero and "No plan changes" | an empty tray with a tick above (replaces the I-15 icon there) |
| IL-05 | Cards, no card matches the filters | a lens over a card, finding nothing |
| IL-06 | Atlas, no concepts yet | a dome with a few faint stars and one bright star (replaces the empty emblem) |
| IL-07 | Progress, no study time in the range | an empty chart and a stopwatch |
| IL-08 | Tasks, nothing left in the view | a list with every box ticked and ∎ |

`EmptyMoment` gained an `art` prop: with it, the illustration replaces the round mark; without it, empty states keep the
emblem as before (No tasks yet, No cards yet, No sessions…).

**Not in this item:** the plan's icon-set rules (24 px grid, 1.75 px stroke) for every icon; the app keeps lucide plus the
drawn marks from R0, whose keys already resolve (icon test). Animated versions belong to A3.

single accent, `EmptyMoment` art, each empty state wired); full unit suite and the v7 design-token lint green; v7
browser suites 386 of 387 in a full parallel run, the one failure ("Calendar Day … back to today") an existing test
race unrelated to this change (passes alone and 28/28 under load, and on main).
