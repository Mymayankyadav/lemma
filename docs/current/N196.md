## N196 Guarded Atlas scheduling

The Nov 20 handoff defines a per-owner scheduling choice in Settings. The shared decision contract uses the native queue before release and honors an explicit Legacy preference after release. Missing preferences resolve to New once the release opens.

The handoff's pinned native math, queue, measurement, fitting, calendar, and scheduler modules were compared with main at `220dada4`. The eight modules used by the mixed-calendar adapter match byte for byte. The standalone archive's selector, fairness, and owner-policy suites passed 60 cases. Its Python application, rollout and tracker suites passed 30 cases. These results establish the reference baseline for the port.
