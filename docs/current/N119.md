## N119 v6 release bugs fixed (Owner task, one PR)

The Owner asked for every open v6 release (G7) bug to be fixed in one PR. Everything is behind `v6Shell`; flag-off screens are unchanged.

**Review undo (#1299).** The durable v6 review run has an "Undo last answer" control. New additive migration `20261209100000_review_runs_undo_last.sql` adds `public.review_runs_undo_last(p jsonb)` (security definer, `authenticated` only, the `review_runs` envelope and `command_receipts` retry rules). In one transaction it checks the run version and that the item is the run's last graded item and the owner's not-yet-undone answer, calls the existing `public.undo_review` to restore the card's previous schedule (which still refuses when a newer answer for the card exists), sets the item back to pending and moves the run back one position (an exhausted run becomes running again). The live adapter calls it once; demo mode undoes its demo review and steps the demo run back (`demoUndoLast`). The MCP registry is unchanged: undo is an app action. Tests: `tests/mcp/sql/review_runs_undo_last.mjs`, `tests/unit/review-run-v6/undo-last.test.ts`, and the release audit's former expected-failure test is now a passing regression test.

**Today and Focus (#1312–#1315).** A focus session's heading is its linked path, else its chosen activity, else "Your focus session" (`src/features/focus/focusContext.ts`); the intention is the description. The Focus page adds the linked checkpoint under the heading, the plan under the bar ("Pomodoro 1 of 4 · 25 min focus / 5 min break"), the intention as a serif line, and the two text actions "Noticed a distraction" and "Park a thought" (moved off Today). Mode, the server phase deadline and the timer lease (Take control / Next phase) are under "Timer details". The reflection is asked for when logging ("What did you learn?"). The mockup draws Finish & log with a dim label (ink-2 on the accent, about 1.4:1 contrast); the app keeps a readable label on purpose.

**Paths, Review, Inbox (#1316–#1318).** Subject headings are `h2` at the mockup size; rows read "Now CPn …" and "3 of 12" (the accessible name keeps "checkpoints"); no "Forecast unavailable" filler. Review has a search row under the header that opens Decks & options and focuses the deck search. A card proposal shows an outlined "Why this card?" that opens the reason and sources.

**Progress (#1319, #1320).** When saved focus overlaps other saved focus or ends in the future, Progress shows "Some saved time entries overlap or need correction. Each minute is counted once." with "Check your log" (`src/features/insights/savedTimeIssues.ts`). The sample-workspace line is a 12px caption.

**Calendar (#1321, #1322).** One "Planning tools" button opens the block-sheet and planner actions. In the Agenda the selected day leads without repeating its date, shows an "N overlapping blocks" chip when blocks overlap, and block cards lead with their time range.

**Cards, Atlas, shell (#1323–#1326, #1302).** A new card starts from the header "+" menu (new "Card" entry → `/cards?new=1`); the Cards list has only Filters. No destination is highlighted on Cards. The shell header takes an optional subtitle (`useV6HeaderTitle(title, subtitle)`); Concept map shows "N concepts · M connections" there. Atlas list rows are plain names: a concept row opens its actions, a group has a quiet expander, status text is for screen readers, "New idea" is a text action at the end. #1302 (Atlas header overlapping the Demo badge) no longer occurs; `tests/e2e/v6-g7-fixes.spec.ts` checks the map-view header inset.

**Kit (#1300).** Kit illustrations scale inside their grid; the release audit has no known-overflow exemptions left.

The capture test scrolls to the top before each screenshot. All 19 release captures are regenerated.
