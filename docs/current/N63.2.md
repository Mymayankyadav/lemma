## N63.2 — proposal draft persistence and live command adapter

Claimed for implementation of the typed N63.1 contract. The N49 `proposal_drafts_command` is the only live mutation path; submitting a saved draft revises a pending proposal and never approves it. Demo persistence will be scoped to a separate sessionStorage key with optimistic draft versions, source-version comparison, filtered cursor pages, deep copies and no owner fields. CI, tests and review status are not yet established.
