## N77 v6 activity preset Settings manager and Focus picker (chat-21963#n6w4)

The N77 branch adds an Activities tab exclusively within the v6 Settings surface while retaining the original seven legacy N28.1 section IDs for existing keyboard/navigation contracts. Activities use the N55 mode-aware PresetApi for bounded full owner-list paging, typed create/edit, precise nonnegative order changes, archive and restore, never raw browser DML. Save, validation and server errors are surfaced visibly; failed edits are retained, while archived presets remain available to restore. The independent src/features/focus/PresetPicker.tsx reads all active owner presets and prepares the selected label/intent, related subject/project/checkpoint IDs, mode and timing settings for a Focus start callback; it cannot mark an archived preset active or independently start a study entry. N72 owns the authoritative captured session configuration when that command lands. Dedicated tests cover all manager operations, typed validation, error handling, >50 owner pages, stable cursor refusal and picker-only active options. No feature flag defaults or data adapters changed. **Owner-authorized start integration (bug #1123):** `TodayFocus.tsx` mounts the active-only picker beside the Focus start control when `v6Shell` is on. A chosen preset pre-fills the intention and passes the chosen owner subject/project/checkpoint links into the existing `startStudyEntry` call. It does not yet alter timer mode or duration: N72 will own the authoritative captured timer configuration. Flag-off Focus does not mount or read presets.


N77 CI correction: native HTML min/max validation on the Activities form previously suppressed the React form submission when a timing value was invalid, so the explicit accessible error could never render. The form now uses `noValidate` and its stricter typed JavaScript validator; the negative regression remains in place. CI revalidation pending. The Owner expanded N77 Scope to include the v6-only TodayFocus mount (bug #1123); the accompanying integration regression exercises the real Focus start callback.
