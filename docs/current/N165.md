### Database and compatibility

One new additive migration, `20261215090000_n165_audit_data_integrity.sql`, supplies the compatible function replacements and new owner-bound RPCs. Existing tracked migrations are unchanged. The old `device_commands_for` handoff remains compatible; the updated app uses `device_commands_recoverable` plus a durable claim ID. Grading accepts an explicit card generation and guards older clients by their expected next repetition. Historical timer timestamps are bounded and chronological, while lease checks use real server time.

Export pages read a single immutable MVCC snapshot, stripped of connector secrets. Its cache is private, owner-bound, expires after 15 minutes, is removed at export completion, and is pruned by pg_cron where available. Its owner foreign key cascades on account deletion. New columns and the private cache are included in the capability inventory.

Native queued actions retain their receipt IDs, timestamps and owners. Legacy unowned queue items are adopted only when the stored native JWT identifies the same owner signing in. A failed delivery or an unidentified queue never assigns private data to a different account. Shared native files are deleted only after the web layer copies and acknowledges their individual paths.
