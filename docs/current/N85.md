## N85 — plan review and drafts in the flagged v6 route

The v6-only proposal branch renders existing and proposed checkpoint targets side by side without mutating the current plan, lists supplied source references and rationale, preserves the established atomic approve/reject hooks, and permits owner draft editing/saving and submit using the N63.2 API. Draft pages are bounded with cursor-loop protection and proposal-ID checks. An optimistic version conflict shows base/current/attempted payloads and reload without overwriting the owner’s draft. Flag-off uses the unchanged legacy PlanProposal component.

**Blocking integration gap:** the existing `getProposal`/project read contracts omit the authoritative proposal and target versions required by N63.2 `createDraft`. The route can safely edit/submit an existing draft but must not fabricate base versions for first-time draft creation. A separate owner-authorized versioned read surface is needed to complete the N85 Done criterion. This PR is not Ready until that is addressed; no unaudited write is attempted.
