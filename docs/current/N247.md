## N247 Exam-mode evaluation and release decision

**Keep exam mode opt-in and the numeric policy in shadow.** The supplied material contains a worked example and a study protocol. It contains no observed counterbalanced outcomes, re-entry measurements or two-to-four-week retention scores.

### Paired simulation

Both policies and the native Atlas comparison received the same synthetic learner, paper draw and twelve minutes in each of 2,000 trials per seed. The fixtures vary transfer, forgetting and weights. The second seed also changes the probabilities of a correct answer.

| Synthetic model | Native Atlas | Weighted teaching | Adaptive probes |
| --- | ---: | ---: | ---: |
| Reference, seed 78191 | 3.8750 | 4.3546 | 4.4359 |
| Mismatched, seed 77417 | 3.9844 | 4.4289 | 4.3437 |

These are expected additional marks in the small linear algebra scenario. Adaptive probes lost 0.0852 marks on average against weighted teaching under the mismatched grading model. Reproduce with `node --experimental-strip-types research/sim/exam-paired.mjs`.

### Observed study

Use `design(blocks)` in `research/sim/exam-evaluation.mjs` with disjoint matched triplets. Save the assignment, proposed minimum exam gain per 100, allowed delayed loss, maximum re-entry minutes and review burden before starting. Rotate Atlas, weighted teaching and adaptive probing through all three positions. Obtain an independent pretest and unseen transfer score after equal budgets, then separate recall and proof scores after equal delays of 14–28 days. Retain every family, including deferred ones.

The report reads an optional `trial` object alongside exported decisions. Set `source` to `observed`, supply `registeredAt`, the original `blocks`, a `gate`, `families` and `returnComparisons`. The runnable input example in `tests/unit/exam/evaluation.test.ts` defines the fields and units. Score fractions run from zero to one. The first comparison is the paired change from pretest to transfer per 100 marks. Intervals use a deterministic family-block bootstrap. A small number of blocks makes those intervals exploratory.

For re-entry, score the same snapshot with full history and with pre-exam history. Record time to substantive course work, needless diagnostics and wrongly skipped checks. Record idea usefulness on return, prep authoring time, duplicate proposals and later review minutes. Predictions frozen before responses support Brier score, log loss, absolute mark error and range coverage, grouped by form, facet, assistance and prior status. Pass explicit prospective `assessments` for separate transfer items. Any recommendation to release still requires independent review.

The critical regression tests cover two simultaneous idea drafts through separate browser sessions and PostgreSQL connections, a late questionnaire answer after a pause, a shorter agenda slot before a fixed appointment, the return to the pre-existing course queue, private exam rubrics and identical retry receipts. Independent review of the merged feature and observed longitudinal results remain release gates.
