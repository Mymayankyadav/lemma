## Atlas v3 React first pass

Adds ProficiencyValue, IntervalBar, StageStrip, KindChip, GapBadge, LinkKindChip, FitMeter, CardBudget and EstimateRange; numerical values share the backend core. Concept sheets show facets and attempts, kinds can be edited, links can be decided, and Themes/Bridges have initial views. Progress, Today, checkpoint readiness, path estimates, sessions, proposals, plan review and Settings are wired. Kit includes examples. Demo mode has synthetic attempts and a link proposal; no production text is copied.

New UI unit tests cover displayed intervals, sessions, inference labels, stage states and accessible uncertainty. Phone e2e specs were added. Chromium installation failed with a truncated archive, so no browser-pass claim is made.

Remaining: finish filters, bridge graph/opportunity display, calibration chart, planner selection, full template/conversion e2e and visual/large-text review.
