## N244 Prospective exam forecasts

A detailed exam read and each active planning decision in an exam list freeze the qualitative action, numeric alternatives, rationale and row predictions before the connector returns. The log is owner-readable, append-only, exportable and purged with its sitting. A log outage leaves the qualitative recommendation available. Resume reads do not inflate the log.

The numeric policy prices one prerequisite-aware lesson or four possible probe outcomes and fills spare minutes with a finite pool of timed corrections. Every branch receives the same follow-up time. The forecast uses action-type recovery seeds and blueprint ranges. Pending, voided, deferred and unscorable evidence cannot train effect estimates. The selector serves in shadow.

Run the offline report with Node 22.18 or newer. Pass an owner export containing `exam_decisions` and `exam_attempts` to `node --experimental-strip-types research/sim/exam-evaluation.mjs export.json`. It replays each frozen model, verifies the SHA-256 input hash, and reports disagreements with the shown choice. The prediction audit matches the latest unambiguous forecast on the same owner, sitting, blueprint version and row before the recorded response.

The research example returns 4.3000 marks for teaching immediately and 4.8225 for asking first. The check breaks even at 2.31 minutes. Both extreme priors choose direct teaching. Four minutes select corrections worth 1.6 marks.
