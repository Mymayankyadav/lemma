## N240 Exam preparation through MCP

Use `study` to create a dated `exam_sittings` record for a project, add scored task families to its blueprint, and activate it. Activation captures the current course checkpoint and question. Each project can have one active sitting. `resume` shows the exam and the suggested next action alongside the course bookmark. `get(what=exam, project=<slug>)` shows coverage, the evidence behind each row, exposed marks, compulsory conflicts and the runner-up. Pass a sitting ID to inspect its history after finishing.

Record a response with `exam_attempts record` and the delivery reference of the original answer. Corrections and voids update the planner. Reading, timeouts and unanswered questions provide no ability score. Save a retrieval target with `card_ideas save`. Repeated sightings merge. A draft goes through the existing proposal approval process. Pausing returns the learner to ordinary study. Finishing requires the learner’s explicit answer about whether the paper took place.

The three resources use owner-scoped commands, optimistic versions, operation receipts and journalled undo. The owner export and account deletion include the new records. A stable read joins the current blueprint to subject concepts and returns up to 2,000 live observations from the last 120 days. The app and MCP use the same planner. A pending tutor handoff includes the active exam when available. N241 adds the opt-in Path interface in this PR.
