## N208 Tutor scratch and photo answers

The `tutorScratch` flag adds drawing and camera or gallery images to a learner turn. The composer and offline queue keep image drafts in owner-scoped IndexedDB. Images are re-encoded and bounded before upload. The migration binds owner-folder objects to the learner turn in its transaction, and the granted MCP read returns inline images. Owner export includes image bytes. The attachment table cascades with the turn, and the cleanup worker purges orphaned objects. The flag defaults off. The two migrations require review before release.

The browser test disconnects the thread endpoint, reloads an image-only answer from IndexedDB, and confirms one owner-folder upload and turn submission on reconnect. The test uses mocked Supabase responses. A confirmed receipt clears the submitted attachment IDs while preserving edits made during the send.

An isolated Supabase Storage API v1.89.12 and PostgREST v14.5 backed by PostgreSQL 17 verified uploads and downloads with two signed test users. The run checked UUID paths, MIME and size limits, owner-only reads and writes, duplicate upload lookup, an atomic bind and receipt replay, and cleanup of expired unbound bytes. The staged migrations ran after the existing migration chain. Production verification follows the reviewed deployment.
