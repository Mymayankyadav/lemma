## Tutor ranking, equations and accepted answer text

### Handoff contract

In the existing MCP study envelope, use schema version 1, resource tutor_answer_aids, the answering handoff ID, and a fresh UUID per mutation. A set replaces the entire aid. Optional expectedVersion compares against the current aid version, with zero for the first aid. A repeated operation ID and identical command return the original receipt even after a newer set. An operation ID reused with a different command is rejected. The existing MCP contract already prescribed a fresh UUID per set. The persisted aid ID identifies its turn's aid across replacements.

The optional ranking object has version 1 and up to 32 hints and 32 declared symbols. Hints specify a stable ID, a canonical entry of kind word, phrase or symbol, optional aliases, priority prefer, neutral or deemphasize, and role given, learner, neutral, alternative or goal. The same canonical entry can appear under several scopes with the same ID. IDs and aliases cannot claim different entries within a kind. Prose identity uses Unicode compatibility normalization, case folding and collapsed space. LaTeX symbols remain case-sensitive. A scope may specify subject ID, checkpoint step identifier, prose or equation mode, up to 12 typed prefixes, and up to 12 phrase states. The handoff's get result includes the subject and step IDs for setting a scope.

The unified strip retains case in symbol prefixes and slot identities, so `X` and `x` can coexist. Scoped aliases share a family when their hint applies. Words share an inflection family when the same pool offers the base and a regular plural or verb form. Independent terms such as `compact`, `compare` and `contradiction` have separate families. The replay reads the family's displayed identity from the same buttons it measures. Legacy withholding keeps its case-insensitive word matching, independently of symbol ranking.

Declarations give a symbol the role set, map, ambient, bound or unknown and may specify ambient, domain or codomain. A binder has an ID and optionally a parent binder in the same aid. The Equation editor recognizes an unambiguous declared symbol after a typed quantifier under the active parent binder. Leaving its delimiter group or row removes the local binding. Conflicting declarations at the same depth supply no relation evidence. The keyboard can use a given relation to rank a known symbol after the learner writes a compatible relation. Common insertion eligibility still decides whether the slot permits an operand.

To undo the most recent changed set on that handoff, send operation undo, a fresh operationId, the current expectedVersion, and patch containing the set's operationId. The undo restores the preceding data and increments the row version. An undo of the first set leaves an empty, versioned aid. Fetch the current aid with get what=tutor_answer_aids before changing it after a version conflict. The database binds the write and receipt to the owner, turn and still-valid answering grant. A deleted or superseded reply no longer supplies active hints. Missing or unknown ranking data carries neutral priority while the legacy withholding fields still apply.

### Editing and provenance

The grammar checks fraction arguments, optional root indices, nested delimiters, and named environments. Matrix rows use the first completed row's width. Separators must be inside a compatible body at its own nesting level. The Equation sheet offers grammar continuations in its LaTeX field and checks the exact edit again on acceptance. A partial environment name can be completed with matching ends. The caret remains in open groups for the learner to supply content.

An assisted answer can store up to 32 sorted, non-overlapping retained spans with UTF-16 start and exclusive end offsets. Each span includes its exact text, an input source and, when applicable, the aid ID and version. The database and connector check offsets against the saved answer and exclude image references. Edits preserve the provenance of surviving assisted text, including around a change made in the Equation sheet. Undo restores the earlier spans. A span can cover up to the 2,000-unit answer limit. The existing answer text and inline image ordering are preserved. The tutor sees the spans as flagged text parts in the answer it was granted.

### Checks

The focused Vitest suites cover legacy and future aid versions, Unicode aliases, scope boundaries, binder shadowing, nested equation continuations, exact accepted text around astral characters, image ordering and withholding when ranking cannot be read. The N193 PostgreSQL fixture runs the new rollback tests for owner access, retries, replacement, stale undo, expired and revoked grants and assisted-answer provenance through the owner submission path. The local execution used PGlite with the real pgcrypto extension and the complete migration chain.

### Worker and phone validation

The prose and equation model lookups run in separate workers. The prose queue keeps one active request and the newest waiting request. Responses from earlier editor revisions are discarded. A startup timeout or worker failure selects the verified trigram fallback. The Equation editor can offer structural templates while its model loads. Identifier proposals partition the language model's symbol-class mass before ranking adjustments.

The phone tap fixture used a 393 × 873 Chromium viewport and 4× CPU throttling. The keyboard measures geometry before changing press styles, reuses that gesture's key origin, and leaves caret restoration to one component. The stylesheet uses explicit Tutor keyboard and paper states, and the key preview retains the same text node across presses. In the detailed trace, the largest style recalculation before release went from 136 affected nodes to 5 for the empty draft, and from 351 to 5 with eight equations. The range-max lexicon lookup retrieves the same ranked prefix completions as the former scan, including Unicode continuations and tied ranks.

The post-release trace also found repeated tab-mode storage writes and React updates to closed dialog contents. The mode is persisted when its value changes, empty answers have a zero-offset caret without reading native selection, and settings and drawing controls render their dialog contents when open.
