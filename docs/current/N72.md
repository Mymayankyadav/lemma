## N72 — v6 Focus modes and shell-wide timer

With `v6Shell` enabled, Today offers an explicit open, Pomodoro or Flowtime quick mode as well as the owner activity preset picker. Quick timed modes persist a reusable activity, then pass its ID through `StudyApi.startStudyEntry` so the server captures a stable configuration rather than trusting browser clock settings. Starting a fresh timer acquires that tab's lease; restoring a timer shows an explicit **Take control** action before changing phases. Focus displays the captured mode, phase, cycle and server phase deadline and provides **Next phase** through `StudyApi.nextPhase`. A three-hour warning is advisory and does not silently log time or stop a legitimate long session.

The shared v6 shell now mounts its reserved `FocusAccessorySlot` with a live/demo `StudyApi.activeStudyEntry` view on every signed-in route, above the dock and above Inbox decisions. Pausing, resuming and opening Focus all use the canonical entry. Today's own accessory is retained only for flag-off compatibility, without introducing a second session record. A session change event prompts refresh in the accessory, while navigation, focus, connectivity and periodic visible reads catch up across routes. This is a view of server state, not a second timer authority.

**I drifted** may optionally exclude a positive whole-minute duration using `StudyApi.excludeMinutes`, after the user explicitly takes control. The exclusion receipt is remembered if the separate drift-notice write fails, preventing a duplicate deduction on retry. Without the v6 flag, the prior drift and Focus surfaces are unchanged. Browser countdowns are display-only; the server owns deadline, intervals, lease and exclusion versions.

Focused regressions live in `tests/unit/focus/modes.test.tsx` and `tests/e2e/v6-focus-modes.spec.ts`. Live quick-mode linking depends on the existing study/preset command path; the separate N109 command-registry/link update must land for full MCP parity. Native background running and OS Live Activities are not part of this web UI.
