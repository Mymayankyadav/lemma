## N222 Equation Assist in Lemma Pad

In development and test builds, enable `equationAssist` in the existing
feature-flag query. For example, open
`/lemma/?demo=1&flags=v7Shell,equationAssist#/pad?path=real-analysis&checkpoint=CP4`.
The flag defaults off for production builds.

Open **Equation Assist** in the Pad and select a single bounded expression or
declaration. The picker previews LaTeX and edits the selected span only when
the learner chooses a reading. Pad's existing undo applies to the insertion.
An active IME or a changed selection prevents a stale candidate from being
applied.

`root 2` offers a square root. A selection like `x2+y2=2` offers distinct
power, subscript, and coefficient readings. Nearby terms such as *circle*,
*sequence*, and *linear equation* rank those readings. Supported polynomial
declarations and explicit quantifiers receive LaTeX candidates from local
rules. When a polynomial's indeterminate is unspecified, the reading that
preserves that wording is offered first.

The fallback is autoeq v1.4 with its Apache-2.0 INT8 encoder, decoder, vocabulary,
and reference beam search. Its pinned graphs total about 4.2 MB. The worker
receives only the bounded selection. It fetches verified static assets from
Lemma and shares the already-packaged ONNX Runtime WASM binary. The web app
can reuse cached assets offline after first use. Capacitor bundles the assets
with the Android app.

Typing shortcuts such as `sqrt(`, `frac(`, and `x^` offer only notation slots.
The learner chooses a slot and supplies its contents. The typing path uses
Pad's existing templates and leaves model inference to Equation Assist.

Verification covers ranked interpretations, proof declarations, notation slots,
undo, cancellation on reselection, offline model reuse, and the existing Pad
keyboard and symbol recognizer. Web tests use a 390 × 844 Chromium viewport.
The Android web build and Capacitor sync include both verified graphs and one
shared WASM asset. Physical Android latency has yet to be measured.
