## N105.2 Atlas concept editing in v6, demo and live

N105.2 completes the app-facing half of N105.1's audited owner graph command. LemmaApi exposes typed create, name/blurb edit, reparent, prerequisite/related link/unlink, server merge impact preview, and expected-version merge. The live adapter sends every write only through authenticated owner concepts_command with stable operationId replay after uncertain outcomes; it carries no user-supplied owner ID. Current versions are included in Atlas reads, and malformed replies or stale versions fail explicitly.

Demo matches the owner operations with version increments, subject/hierarchy checks, prerequisite cycle refusal, link deduplication and transactional merge of graph edges, parents, linked notes, checkpoints and misconceptions. The new v6 Atlas editor exposes create/edit/reparent and links, requires a preview with both source/kept versions before merge, and refetches the Atlas after successful mutations. N86's preview-only caller remains read-only, as existing unit tests require. Flag-off and map pin paths remain unchanged.

New unit tests cover typed RPC envelopes, immutable retry IDs, owner-authenticated calls, conflicts, demo lifecycle/cycles/merge, and the v6 editor/merge confirmation. No migration, service-role browser credential, new dependency or feature-flag default changes.
