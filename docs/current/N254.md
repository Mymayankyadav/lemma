# N254 · Lemma theme and tutor input

The warm day and night palette, subject emblems and UI token HTML are documented in [the palette note](palette-2026-11-26.md) and [the subject note](subject-palette-2026-11-26.md).

While typing prose, the left suggestion keeps the learner's exact spelling. The center and right suggestions apply the two highest-ranked distinct alternatives. Long words condense and then elide in the middle, with the full spelling available to assistive technology. Only actual alternatives count toward feedback and learning.

The editable chat preloads a dictionary in a dedicated worker before the first key. Rapid edits replace the pending query. Brief keyboard closes reuse the index. The worker releases its index and draft context after 30 seconds with the keyboard closed, when the document is hidden, when the user selects the device keyboard, or when the tutor or account changes. The UI searches the sorted tap-correction file directly. Browsers without a working worker use the bundled spelling engine after paint.

The iPad dock extends to the edges of its window. Its keys retain the inner gutter and home-indicator space. The pin fills the native dictation key's cell so the space bar starts and ends at the reference positions. The composer keyboard icon switches input methods and restores the selection in the same tap.

The quiz title, single-choice answers, multiple-choice answers and pinned question now use the app's inline math renderer. Selection and saving still use the original answer indices.
