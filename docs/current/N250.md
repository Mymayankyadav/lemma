## N250 Navigation, typing and optional PWA model installation

Today keeps its last day summary visible during refresh. Its cache is scoped to the owner or demo profile, account generation, day and time zone. The closed-day indicator reads the plan status separately from its items. Study details load on expansion, and exam controls load when there are sittings to show.

Opening a path or checkpoint starts its code and data on press or keyboard focus. The live reads filter by owner and destination, page large result sets and share identical requests that are already in flight. Back restores the scroll position and expanded path stage. Page transitions start immediately and respect both motion preferences. The dock and screens share the active focus session, and the hidden tutor timer no longer redraws the conversation every second.

Tutor displays the last confirmed conversation for the same owner and checkpoint while revalidating. New messages appear with a Sending indicator. A failed submission keeps its draft and existing retry rules. Empty prose and new sentences leave the alphabet keyboard free of unsolicited math symbols. Explicit math keys, commands and drawing remain available. Swipe and ink feedback avoid a React render for every pointer move.

In **Settings → Tutor → Writing aid**, turn on **Try faster typing**. **Download from link** accepts a custom HTTPS URL. **Install model file** accepts the private FP16 package. The installer verifies all four files and caches the runtime and count model for offline use. Cancellation, invalid files and failed transfers leave a previous install usable.
