## N91 History correction schema and parameter snapshots (in progress)

The branch adds additive correction metadata on `session_events`, a reference to immutable owner-scoped FSRS parameter snapshots on `reviews`, and a new `review_parameter_sets` table. Legacy timestamps read as `coalesce(occurred_at, created_at)`; historical grades with no recorded settings remain explicitly unknown rather than guessing current weights. Owner RLS and explicit browser DML revocations close unaudited writes; new parameter rows have action journaling and generic undo registry membership. A full-migration PGlite test asserts schema, owner isolation, grants and registry. The owner-checked correct/void functions, checkpoint re-derivation and review schedule replay/replacement are NOT yet implemented; this PR remains unready and cannot merge until those and their tests are finished.
