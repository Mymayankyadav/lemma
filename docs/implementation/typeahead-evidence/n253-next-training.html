What counts as success

For each answer count manual actions M and assisted actions A. Calculate pooled KSR as 1 − ΣA / ΣM. Calculate boundary coverage as visible top-three exact edits divided by all scheduled boundaries, including empty menus and late responses. Exactness covers the inserted text, UTF-16 replacement span, caret and resulting selection. Report started edits and symbols separately.

The first private GPU experiment

Run two students in a single versioned Kaggle T4 batch. Each student has 2,307,457 parameters and uses the frozen 16,384-piece tokenizer, a 128-dimensional tied embedding, a 192-unit GRU, a projection back into the embedding space, and a fit-only word vocabulary. Use identical initialization, row order, optimizer settings and exposure. Evaluate the fixed third epoch. The comparison measures what direct supervision and the teacher each contribute to shortlist ranking. Teacher performance on the earlier browser pilot provides a separate reference.

The first batch contains 20,000 lowercase prose-word decisions from 5,000 public training groups. There are 2,500 explanation groups, 500 proof groups and 2,000 parsed question–reply groups. In each group two positions supply both a boundary and a one-to-three-letter prefix. The split by group yields 16,072 fit rows and 3,928 within-training calibration rows. The pinned corpus includes texts seen by the existing counts and teacher. This batch can test the training mechanism and compare the two students.
