# N192 — Ship dedicated Lemma Pad page, custom math keyboard and offline editor

**Stage:** Build · **Queue status:** open · **Needs:** N193 · **Claim:** [existing PR #1535](https://github.com/Mymayankyadav/lemma/pull/1535)

## Outcome and exact Done

Extend existing PR #1535 into a shipped, discoverable full-page Lemma Pad—not merely an embedded checkpoint panel or hidden offline shortcut. Add a first-class route, in-app entry and deep-link recovery; ship a usable custom mathematics keyboard while retaining native keyboard/IME and caret support. Preserve current revisioned offline text, KaTeX preview, ink, backup/export, owner isolation and explicit tutor selection.

## What the next agent actually does
1. Continue PR #1535 0c2504f and preserve all existing offline and exports work. Reuse the existing Pad-to-tutor bridge after N193 defines the canonical receiver.
2. Register an actual `/pad` full-page route with a labeled link in the app navigation/More menu and checkpoint entry. The page lists/selects only owner-authorized checkpoints; show an informative no-checkpoint state, with an offline option only for previously authorized cached checkpoints.
3. Build a dedicated on-screen math keyboard dock: common operations, algebra, geometry/calculus symbols, fractions, exponents, roots, brackets and template slots; Backspace, navigation, Enter, undo/redo and hide/show. Preserve normal hardware/soft keyboard, IME composition, selection and caret; insert symbols/templates at the actual selection without duplicating text.
4. Handle 320–390px widths, portrait/landscape, safe areas, scroll with focused caret visible above the custom keyboard and Android soft keyboard. Avoid double keyboard obstruction and do not force a proprietary input method.
5. Use accessible labeled keys, consistent focus restoration, announced modes, reliable touch targets and TalkBack/physical keyboard behavior. Keep math preview bounded and never execute unsanitized input.
6. Keep IndexedDB revisions, corrupt-head recovery, owner-bound account switching, explicit backup/export/import/delete and sharing grants. Only an explicit selected excerpt is previewed, added and submitted to the tutor; edits remain local otherwise.
7. At the coordinated N198 release, make Pad page and custom keyboard visible by default (build flag can remain off during implementation), with optional keyboard hide/show retained as a per-editor preference.

## Required acceptance evidence
- [ ] Direct navigation/reload to `/pad` works online, and an authorized cached Pad works after two cold offline PWA reopens without a new login bypass.
- [ ] Custom keyboard inserts correctly around selection and IME, supports undo/redo/templates, works without network and is usable with TalkBack/hardware keyboard and at 320–390px.
- [ ] Nothing sent to tutor until explicit preview/Add/Save; exports and account deletion preserve owner isolation, and the Android share grant is cleared on sign-out.
